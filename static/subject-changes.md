# UWaterloo Course Subject Code Changes

Some course subject codes at the University of Waterloo have been renamed over the years. Notes on this site may use either the old or new code depending on when the course was taken.

## Renamed Codes

| Old Code | New Code | Old Name | New Name | Notes |
|----------|----------|----------|----------|-------|
| SMF | SRF | Sexuality, Marriage & Family | Sexualities, Relationships & Families | Department renamed |
| MGMT | MSE | Management Sciences | Management Science & Engineering | Rebranded under Faculty of Engineering |
| MSCI | MSE | Management Sciences | Management Science & Engineering | Alternate old code for same dept |
| RS | RCS | Religious Studies | Religion, Culture & Spirituality | Program renamed in Faculty of Arts |
| AHS | HEALTH | Applied Health Sciences | Health | Faculty of Health general subject code renamed |
| GEOG 181 | GDS 181 | Geography | Geospatial Data Science | Course moved to new GDS subject code |

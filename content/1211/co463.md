Convex optimization sits at the intersection of analysis, geometry, and computation. It asks: given a convex objective function over a convex feasible region, how do we find and certify minimizers, and how fast can algorithms converge? The special structure of convexity — every local minimum is global, every sublevel set is convex, every supporting hyperplane touches from below — makes these questions far more tractable than general nonlinear programming.

This course, taught by Prof. Walaa Moursi at the University of Waterloo (Winter 2021), develops the theory from first principles: convex sets, convex functions, conjugate duality, subdifferential calculus, and modern proximal splitting algorithms.

## Chapter 1: Convex Sets

### 1.1 Introduction and Motivation

The central problem throughout this course is:
\[ \min_{x \in C \subseteq \mathbb{R}^n} f(x) \tag{P} \]
When \(C = \mathbb{R}^n\) and \(f\) is differentiable, minimizers satisfy Fermat's rule \(\nabla f(x) = 0\). The course extends this to the harder setting where \(f\) is **convex but not necessarily differentiable** and \(\emptyset \neq C \subsetneq \mathbb{R}^n\) is a **convex constraint set**.

### 1.2 Affine Sets and Subspaces

Before defining convex sets, it is useful to introduce affine sets — the simpler, "flat" sets that form the backdrop for convex geometry. Affine sets allow unrestricted linear combinations, while convex sets only allow convex (weighted-average) combinations.

<div class="definition">
<strong>Definition</strong> (Affine Set). A set \(S \subseteq \mathbb{R}^n\) is <strong>affine</strong> if for all \(x, y \in S\) and <em>all</em> \(\lambda \in \mathbb{R}\),
\[ \lambda x + (1 - \lambda)y \in S. \]
Note the key difference from convexity: \(\lambda\) ranges over all of \(\mathbb{R}\), not just \([0,1]\).</div>

<div class="definition">

<strong>Definition 1.2.2</strong> (Affine Subspace). An <strong>affine subspace</strong> is any nonempty affine set \(\emptyset \neq S \subseteq \mathbb{R}^n\).

</div>

<div class="example">

<strong>Example 1.2.1.</strong> Let \(L\) be a linear subspace of \(\mathbb{R}^n\) and \(a \in \mathbb{R}^n\). Then \(L\), \(a + L\), \(\emptyset\), and \(\mathbb{R}^n\) are all examples of affine sets.

</div>

Unlike convex sets, affine sets are closed under arbitrary "linear interpolation-and-extrapolation". Geometrically, an affine set is a "flat" — a point, line, plane, or hyperplane that extends infinitely in all directions along itself. Every linear subspace is affine (set \(\lambda = 0\) to see it contains \(0\)), and every translate \(a + L\) of a linear subspace \(L\) is affine. Conversely, every nonempty affine set \(A\) has a corresponding linear subspace \(L := A - A = \bigcup_{a \in A}(A - a)\).

![Affine set in R²](/pics/co463/affine-set.png)

<div class="definition">
<strong>Definition</strong> (Affine Hull). The <strong>affine hull</strong> of \(S \subseteq \mathbb{R}^n\) is
\[ \operatorname{aff}(S) := \bigcap_{\substack{T \supseteq S \\ T \text{ affine}}} T, \]
the smallest affine set containing \(S\).</div>

The affine hull is the analogue of the linear span: just as the span is the smallest subspace containing a set, the affine hull is the smallest flat containing it. The dimension of a convex set is defined as the dimension of its affine hull, which captures the "intrinsic" dimension irrespective of the ambient space.

### 1.3 Convex Sets

With affine sets as our backdrop, we now define the central objects of this course. Convex sets are the natural setting for minimization because any local minimum of a convex function over a convex set is automatically a global minimum — a guarantee impossible in the general nonconvex setting.

<div class="definition">
<strong>Definition</strong> (Convex Set). \(C \subseteq \mathbb{R}^n\) is <strong>convex</strong> if for all \(x, y \in C\) and \(\lambda \in (0,1)\),
\[ \lambda x + (1-\lambda)y \in C. \]
Geometrically: the line segment joining any two points of \(C\) lies entirely in \(C\).</div>

The geometric picture is the key intuition: a set is convex if you can "see" every point from every other point without leaving the set. This "no hidden corners" property is precisely what makes convex optimization tractable.

![Convex vs non-convex sets](/pics/co463/convex-vs-nonconvex-set.png)

<div class="example">

<strong>Example 1.3.1.</strong> \(\emptyset\), \(\mathbb{R}^n\), closed balls, affine sets, and halfspaces \(\{x : \langle a, x\rangle \leq b\}\) are all examples of convex sets.

</div>

One of the most important properties of convex sets is that they are stable under intersection — a fact that lets us build complex feasible regions by intersecting simple ones.

<div class="theorem"><strong>Theorem</strong> (Intersection of Convex Sets). The intersection of an arbitrary collection of convex sets is convex.</div>

<div class="proof"><strong>Proof.</strong> Let \(\{C_i\}_{i \in I}\) be convex, \(C = \bigcap_{i \in I} C_i\). For \(x, y \in C\) and \(\lambda \in (0,1)\), since \(x, y \in C_i\) for every \(i\), convexity of each \(C_i\) gives \(\lambda x + (1-\lambda)y \in C_i\). Hence it lies in \(C\). \(\square\)</div>

This theorem, whose proof is almost immediate, has enormous practical consequences: any optimization problem with multiple linear or convex constraints defines a convex feasible set, and the intersection theorem ensures we inherit all the geometric benefits of convexity.

<div class="theorem"><strong>Corollary.</strong> For any index set \(I\) and vectors \(b_i \in \mathbb{R}^n\), scalars \(\beta_i \in \mathbb{R}\), the set \(C = \{x \in \mathbb{R}^n : \langle x, b_i\rangle \leq \beta_i,\ \forall i \in I\}\) is convex.</div>

### 1.4 Convex Combinations and the Convex Hull

The definition of convexity involves combinations of just two points. But iterating this, we can take weighted averages of arbitrarily many points — the resulting objects are convex combinations, and they characterize convex sets internally.

<div class="definition"><strong>Definition</strong> (Convex Combination). A vector \(\sum_{i=1}^m \lambda_i x_i\) is a <strong>convex combination</strong> of \(x_1, \ldots, x_m\) if \(\lambda_i \geq 0\) for all \(i\) and \(\sum_{i=1}^m \lambda_i = 1\).</div>

A convex combination is a generalized weighted average with nonnegative weights summing to one. Geometrically, it is a point strictly "inside" the simplex spanned by \(x_1, \ldots, x_m\).

![Convex combination of three vertices](/pics/co463/convex-combination.png)

<div class="theorem"><strong>Theorem.</strong> \(C \subseteq \mathbb{R}^n\) is convex if and only if it contains all convex combinations of its elements.</div>

<div class="proof"><strong>Proof.</strong> The case \(m = 2\) is the definition. For \(m > 2\), induct: write \(\sum_{i=1}^m \lambda_i x_i = (1 - \lambda_m) \sum_{i=1}^{m-1} \frac{\lambda_i}{1-\lambda_m} x_i + \lambda_m x_m\). By induction the first factor is in \(C\), and convexity gives the result. \(\square\)</div>

The inductive step re-normalizes the first \(m-1\) weights to sum to one, making the outer combination a two-point convex combination — a clean reduction to the base case. This argument also shows that convexity is equivalent to closure under finite convex combinations.

<div class="definition">
<strong>Definition</strong> (Convex Hull). The <strong>convex hull</strong> of \(S \subseteq \mathbb{R}^n\) is
\[ \operatorname{conv} S := \bigcap_{\substack{T \supseteq S \\ T \text{ convex}}} T, \]
the smallest convex set containing \(S\).</div>

<div class="theorem">

<strong>Theorem 1.4.2.</strong> \(\operatorname{conv} S\) consists of all convex combinations of elements of \(S\).

</div>

This gives a constructive description of the convex hull: any point in \(\operatorname{conv} S\) can be written as a finite convex combination of elements of \(S\).

The convex hull is the "tightest shrink-wrap" around a set — the smallest convex container. Its two equivalent descriptions (as an intersection and as a set of combinations) are both useful: the intersection description makes existence and closure properties immediate, while the combination description gives a constructive handle on the hull's elements.

![Convex hull of a point set](/pics/co463/convex-hull.png)

### 1.5 The Projection Theorem

The **metric projection** onto a convex set is a cornerstone of the theory, enabling both theoretical results (separation, supporting hyperplanes) and algorithms (projected gradient descent). The key question is: given a point \(x\) outside a convex set \(C\), is there a unique closest point in \(C\)?

<div class="definition"><strong>Definition</strong> (Distance Function). For \(S \subseteq \mathbb{R}^n\), the <strong>distance function</strong> to \(S\) is \(d_S : \mathbb{R}^n \to [0,\infty)\) given by \(d_S(x) = \inf_{s \in S} \|x - s\|\).</div>

The distance function measures how far a point is from the set. For closed sets, the infimum is attained; for convex sets, the attaining point is unique.

<div class="definition"><strong>Definition</strong> (Projection). Let \(\emptyset \neq C \subseteq \mathbb{R}^n\) and \(x \in \mathbb{R}^n\). A point \(p \in C\) is a <strong>projection</strong> of \(x\) onto \(C\) if \(d_C(x) = \|x - p\|\). When unique, we write \(P_C(x) := p\).</div>

The projection operator is the geometric analogue of rounding to the nearest element: given any point, project it to the nearest feasible point in \(C\). Both closedness and convexity are needed for the projection to exist and be unique.

![Projection onto a closed convex set](/pics/co463/projection-theorem.png)

Without closedness, \(P_C(x)\) may not exist (no closest point reached). Without convexity, the projection may be non-unique.

Two lemmas prepare the proof of the Projection Theorem.

<div class="lemma">

<strong>Lemma 1.5.1.</strong> For all \(x, y, z \in \mathbb{R}^n\),
\[ \|x - y\|^2 = 2\|z - x\|^2 + 2\|z - y\|^2 - 4\left\|z - \frac{x+y}{2}\right\|^2. \]

</div>

<div class="lemma">

<strong>Lemma 1.5.2.</strong> For \(x, y \in \mathbb{R}^n\),
\[ \langle x, y\rangle \leq 0 \iff \forall \lambda \in [0,1],\; \|x\| \leq \|x - \lambda y\|. \]

</div>

The Projection Theorem is one of the central results of this chapter: it not only guarantees existence and uniqueness of the projection, but gives a clean variational characterization that generalizes Fermat's rule.

<div class="theorem">
<strong>Theorem 1.5.3</strong> (Projection Theorem). Let \(\emptyset \neq C \subseteq \mathbb{R}^n\) be closed and convex. Then:
<ol>
<li>For every \(x \in \mathbb{R}^n\), \(P_C(x)\) exists and is unique.</li>
<li>For every \(x \in \mathbb{R}^n\) and \(p \in \mathbb{R}^n\),
\[ p = P_C(x) \iff p \in C \text{ and } \forall y \in C,\ \langle y - p,\, x - p\rangle \leq 0. \]</li>
</ol></div>

<div class="proof">
<strong>Proof sketch (existence).</strong> Take \(c_n \in C\) with \(\|c_n - x\| \to d_C(x)\). By the parallelogram-like identity, \(\|c_n - c_m\|^2 \leq 2\|c_n - x\|^2 + 2\|c_m - x\|^2 - 4d_C(x)^2 \to 0\), so \((c_n)\) is Cauchy, converging to some \(p \in C\) (by closedness). Continuity of \(\|\cdot\|\) then gives \(\|p - x\| = d_C(x)\).

<strong>Uniqueness</strong> follows by applying the same identity to two minimizers \(p, q\): it forces \(\|p - q\|^2 \leq 0\).

<strong>Characterization (ii)</strong>: \(p = P_C(x)\) iff \(p\) minimizes \(\|x - \cdot\|\) over \(C\). For any \(y \in C\) and \(\alpha \in [0,1]\), the point \(\alpha y + (1-\alpha)p \in C\) gives \(\|x - p\|^2 \leq \|x - \alpha y - (1-\alpha)p\|^2\). Expanding and dividing by \(\alpha > 0\), then letting \(\alpha \to 0^+\) yields \(\langle y - p, x - p\rangle \leq 0\). \(\square\)</div>

The existence proof uses the parallelogram identity to show that a minimizing sequence is Cauchy, then appeals to closedness; uniqueness uses the same identity to force any two minimizers to coincide. The variational characterization is derived by a first-order condition along segments from \(p\) towards any other feasible point.

<div class="example">

<strong>Example 1.5.4.</strong> Fix \(\varepsilon > 0\) and let \(C = \overline{B}(0;\varepsilon)\) be the closed ball of radius \(\varepsilon\) around \(0\). For all \(x \in \mathbb{R}^n\),
\[ P_C(x) = \frac{\varepsilon}{\max(\|x\|,\varepsilon)}\,x. \]
That is, \(P_C(x) = x\) if \(x \in C\), and otherwise \(x\) is scaled to have norm \(\varepsilon\).

</div>

**Firm nonexpansiveness of projection.** For any \(x, y \in \mathbb{R}^n\),
\[ \|P_C(x) - P_C(y)\|^2 \leq \langle P_C(x) - P_C(y),\, x - y\rangle. \]
In particular, \(P_C\) is **nonexpansive**: \(\|P_C(x) - P_C(y)\| \leq \|x - y\|\).

![Nonexpansiveness of projection](/pics/co463/projection-nonexpansive.png)

### 1.6 Convex Set Operations

<div class="definition"><strong>Definition</strong> (Minkowski Sum). \(C + D := \{c + d : c \in C,\, d \in D\}\).</div>

<div class="theorem"><strong>Theorem</strong> (Minkowski). If \(C_1, C_2 \subseteq \mathbb{R}^n\) are convex, so is \(C_1 + C_2\).</div>

<div class="theorem"><strong>Proposition.</strong> If \(C, D \neq \emptyset\) are closed, convex, and \(D\) is bounded, then \(C + D\) is closed and convex. (Boundedness cannot be dropped in general.)</div>

<div class="theorem"><strong>Theorem.</strong> If \(C \subseteq \mathbb{R}^n\) is convex and \(\lambda_1, \lambda_2 \geq 0\), then \((\lambda_1 + \lambda_2) C = \lambda_1 C + \lambda_2 C\).</div>

### 1.7 Topological Properties

<div class="definition">
<strong>Definitions.</strong>
<ul>
<li><strong>Interior</strong>: \(\operatorname{int} C = \{x : \exists \varepsilon > 0,\, x + \varepsilon B \subseteq C\}\) where \(B = \overline{B}(0;1)\).</li>
<li><strong>Closure</strong>: \(\overline{C} = \bigcap_{\varepsilon > 0} (C + \varepsilon B)\).</li>
<li><strong>Relative interior</strong>: \(\operatorname{ri} C = \{x \in \operatorname{aff} C : \exists \varepsilon > 0,\, (x + \varepsilon B) \cap \operatorname{aff} C \subseteq C\}\).</li>
<li><strong>Dimension</strong> of convex \(C\): \(\dim C := \dim(\operatorname{aff} C)\).</li>
</ul></div>

<div class="theorem">

<strong>Proposition 1.7.1.</strong> Let \(C \subseteq \mathbb{R}^n\). If \(\operatorname{int} C \neq \emptyset\), then \(\operatorname{int} C = \operatorname{ri} C\).

</div>

When \(\operatorname{int} C \neq \emptyset\), we have \(\operatorname{ri} C = \operatorname{int} C\), since \(\operatorname{aff} C = \mathbb{R}^n\) in that case.

<div class="theorem"><strong>Proposition 1.7.2.</strong> Let \(C \subseteq \mathbb{R}^n\) be convex. For all \(x \in \operatorname{int} C\) and \(y \in \overline{C}\), the half-open segment \([x, y) \subseteq \operatorname{int} C\).</div>

This is the key "line from interior to boundary stays in interior" property. An analogous result holds for the relative interior:

<div class="theorem">

<strong>Theorem 1.7.3.</strong> Let \(C \subseteq \mathbb{R}^n\) be convex. For all \(x \in \operatorname{ri} C\) and \(y \in \overline{C}\), \([x,y) \subseteq \operatorname{ri} C\).

</div>

This implies:

<div class="theorem">
<strong>Theorem 1.7.4.</strong> For convex \(C\):
<ol>
<li>\(\overline{C}\) is convex.</li>
<li>\(\operatorname{int} C\) is convex.</li>
<li>If \(\operatorname{int} C \neq \emptyset\), then \(\operatorname{int} C = \operatorname{int} \overline{C}\) and \(\overline{C} = \overline{\operatorname{int} C}\).</li>
</ol></div>

<div class="theorem"><strong>Theorem 1.7.5.</strong> For convex \(C \subseteq \mathbb{R}^n\): \(C \neq \emptyset\) if and only if \(\operatorname{ri} C \neq \emptyset\). Moreover, \(\operatorname{ri} C\) and \(\overline{C}\) are convex.</div>

### 1.8 Separation Theorems

Separation theorems are among the most powerful tools in convex analysis. The geometric intuition is vivid: if two convex sets are disjoint, a hyperplane can be "slid between" them, separating them cleanly. This geometric fact has far-reaching analytic and algorithmic consequences — it is the foundation of duality theory, optimality conditions, and the theory of supporting hyperplanes.

<div class="definition">
<strong>Definition</strong> (Separation). \(C_1, C_2 \subseteq \mathbb{R}^n\) are <strong>separated</strong> if there exists \(b \in \mathbb{R}^n \setminus \{0\}\) such that
\[ \sup_{c_1 \in C_1} \langle c_1, b\rangle \leq \inf_{c_2 \in C_2} \langle c_2, b\rangle. \]
They are <strong>strongly separated</strong> if the inequality is strict.</div>

Geometrically, separation says that the sets lie on opposite sides of the hyperplane \(\{x : \langle x, b\rangle = c\}\) for some \(c\). Strong separation means there is a positive gap between the sets, while weak separation allows them to touch the separating hyperplane from opposite sides.

<div class="theorem"><strong>Theorem 1.8.1</strong> (Strong Separation from a Point). Let \(\emptyset \neq C \subseteq \mathbb{R}^n\) be closed and convex and \(x \notin C\). Then \(x\) is strongly separated from \(C\).</div>

<div class="proof"><strong>Proof.</strong> Set \(p = P_C(x)\) and \(b = x - p \neq 0\). By the projection characterization, for all \(y \in C\): \(\langle y - p, x - p\rangle \leq 0\), i.e., \(\langle y - x, b\rangle \leq -\|b\|^2 < 0\). So \(\sup_{y \in C}\langle y, b\rangle < \langle x, b\rangle\). \(\square\)</div>

The proof is elegantly short: the vector \(b = x - p\) pointing from the projection to \(x\) is exactly the separating direction, and the projection characterization gives the required inequality for free.

![Separation theorem](/pics/co463/separation-theorem.png)

<div class="corollary">

<strong>Corollary 1.8.1.1.</strong> Let \(C_1 \cap C_2 = \emptyset\) be nonempty subsets of \(\mathbb{R}^n\) such that \(C_1 - C_2\) is closed and convex. Then \(C_1\) and \(C_2\) are strongly separated.

</div>

<div class="corollary">

<strong>Corollary 1.8.1.2.</strong> Let \(\emptyset \neq C_1, C_2 \subseteq \mathbb{R}^n\) be closed and convex such that \(C_1 \cap C_2 = \emptyset\) and \(C_2\) is bounded. Then \(C_1\) and \(C_2\) are strongly separated.

</div>

<div class="theorem"><strong>Theorem 1.8.2</strong> (Separation of Disjoint Convex Sets). If \(\emptyset \neq C_1, C_2 \subseteq \mathbb{R}^n\) are closed, convex, and disjoint, then \(C_1\) and \(C_2\) are (at least weakly) separated.</div>

<div class="proof"><strong>Proof sketch.</strong> For each \(n\), set \(D_n = C_2 \cap \overline{B}(0; n)\). By the strong separation corollary, \(C_1\) and \(D_n\) are separated by unit vectors \(u_n\). By compactness (bounded unit vectors), a subsequence \(u_{k_n} \to u\) with \(\|u\| = 1\). Passing to the limit weakens the strict inequality to weak. \(\square\)</div>

<div class="theorem"><strong>Theorem</strong> (Supporting Hyperplane). Let \(\emptyset \neq C \subseteq \mathbb{R}^n\) be convex. For any boundary point \(x_0 \in \partial C\) with \(\operatorname{int} C \neq \emptyset\), there exists \(a \neq 0\) such that \(\langle a, x\rangle \leq \langle a, x_0\rangle\) for all \(x \in C\).</div>

### 1.9 Cones, Tangent Cones, and Normal Cones

The separation theorems motivate a closer look at the local geometry of convex sets near their boundaries. The tangent cone and normal cone formalize the notion of "which directions are feasible" and "which gradients are inward-pointing" at a boundary point — concepts that are indispensable for optimality conditions.

<div class="definition">
<strong>Definitions.</strong>
<ul>
<li>A set \(C\) is a <strong>cone</strong> if \(C = \mathbb{R}_{++} C\) (closed under positive scaling).</li>
<li>The <strong>conical hull</strong> \(\operatorname{cone} C = \mathbb{R}_{++} C\) is the smallest cone containing \(C\).</li>
<li>The <strong>closed conical hull</strong> \(\overline{\operatorname{cone}}(C)\) is the smallest closed cone containing \(C\).</li>
<li>The <strong>tangent cone</strong> to \(C\) at \(x\) is \(T_C(x) = \overline{\operatorname{cone}(C - x)}\) for \(x \in C\), and \(\emptyset\) otherwise.</li>
<li>The <strong>normal cone</strong> to \(C\) at \(x\) is \(N_C(x) = \{u : \sup_{c \in C}\langle c - x, u\rangle \leq 0\}\) for \(x \in C\), and \(\emptyset\) otherwise.</li>
</ul></div>

<div class="theorem">

<strong>Proposition 1.9.1.</strong> Let \(C \subseteq \mathbb{R}^n\). The following hold:
<ol>
<li>\(\operatorname{cone} C = \mathbb{R}_{++} C\).</li>
<li>\(\operatorname{cone} C = \overline{\operatorname{cone}}(C)\) when \(C\) is a cone.</li>
<li>\(\overline{\operatorname{cone}}(\operatorname{conv} C) = \operatorname{conv}(\operatorname{cone} C)\).</li>
<li>\(\overline{\operatorname{cone}}(\operatorname{conv} C) = \operatorname{conv}(\operatorname{cone} C)\).</li>
</ol>

</div>

<div class="lemma">

<strong>Lemma 1.9.2.</strong> Let \(0 \in C \subseteq \mathbb{R}^n\) be convex with \(\operatorname{int} C \neq \emptyset\). The following are equivalent:
<ol>
<li>\(0 \in \operatorname{int} C\).</li>
<li>\(\operatorname{cone} C = \mathbb{R}^n\).</li>
<li>\(\overline{\operatorname{cone}}(C) = \mathbb{R}^n\).</li>
</ol>

</div>

<div class="theorem">

<strong>Theorem 1.9.3.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^n\) be closed and convex, and \(x \in \mathbb{R}^n\). Both \(N_C(x)\) and \(T_C(x)\) are closed convex cones.

</div>

<div class="lemma">

<strong>Lemma 1.9.4.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^n\) be closed and convex with \(x \in C\). Then
\[ n \in N_C(x) \iff \forall t \in T_C(x),\; \langle n, t\rangle \leq 0. \]

</div>

<div class="theorem">

<strong>Theorem 1.9.5.</strong> Let \(C \subseteq \mathbb{R}^n\) be convex with \(\operatorname{int} C \neq \emptyset\), and \(x \in C\). The following are equivalent:
<ol>
<li>\(x \in \operatorname{int} C\).</li>
<li>\(T_C(x) = \mathbb{R}^n\).</li>
<li>\(N_C(x) = \{0\}\).</li>
</ol>

</div>

Tangent vectors point "into" or "along" the set from \(x\), while normal vectors point "outward" — making negative inner products with all feasible directions. Normal and tangent cones are **dual** to each other: \(u \in N_C(x)\) if and only if \(\langle u, t\rangle \leq 0\) for all \(t \in T_C(x)\). When \(x \in \operatorname{int} C\), \(T_C(x) = \mathbb{R}^n\) and \(N_C(x) = \{0\}\).

## Chapter 2: Convex Functions

With the geometry of convex sets in place, we turn to convex functions — the functions that preserve the geometric structure of convex sets in their graphs. Chapter 2 develops the theory from the epigraph definition through the key analytic tools of subdifferentials, conjugates, and proximal operators.

### 2.1 Definitions and Basic Results

A convex function is one whose graph "curves upward" — the chord between any two points on the graph lies above the graph. The cleanest algebraic encoding of this is through the epigraph.

<div class="definition">
<strong>Definition</strong> (Epigraph). The <strong>epigraph</strong> of \(f : \mathbb{R}^n \to [-\infty, \infty]\) is
\[ \operatorname{epi} f := \{(x, \alpha) \in \mathbb{R}^n \times \mathbb{R} : f(x) \leq \alpha\}. \]</div>

The epigraph is the set of points on or above the graph of \(f\). Demanding that this set is convex is equivalent to the classical Jensen inequality — the two formulations are interchangeable, but the epigraph viewpoint makes geometric arguments more transparent.

<div class="definition">

<strong>Definition 2.1.2</strong> (Domain). For \(f : \mathbb{R}^n \to [-\infty, \infty]\),
\[ \operatorname{dom} f := \{x \in \mathbb{R}^n : f(x) < \infty\}. \]

</div>

<div class="definition">

<strong>Definition 2.1.3</strong> (Proper Function). We say \(f\) is <strong>proper</strong> if \(\operatorname{dom} f \neq \emptyset\) and \(f(\mathbb{R}^n) > -\infty\) (i.e., \(f\) never takes the value \(-\infty\)).

</div>

<div class="definition">

<strong>Definition 2.1.4</strong> (Indicator Function). Let \(C \subseteq \mathbb{R}^n\). The <strong>indicator function</strong> of \(C\) is
\[ \delta_C(x) := \begin{cases} 0, & x \in C \\ \infty, & x \notin C. \end{cases} \]

</div>

<div class="definition">
<strong>Definition</strong> (Convex Function). \(f\) is <strong>convex</strong> if \(\operatorname{epi} f\) is a convex set. Equivalently (for proper \(f\)), for all \(x, y \in \operatorname{dom} f\) and \(\lambda \in (0,1)\):
\[ f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y). \]</div>

Properness is a mild regularity condition that rules out degenerate functions that are identically \(+\infty\) or take the value \(-\infty\). Most functions encountered in practice are proper, but the condition becomes important when taking conjugates and infimal convolutions.

<div class="theorem">

<strong>Proposition 2.1.1.</strong> Let \(f : \mathbb{R}^n \to [-\infty, \infty]\) be convex. Then \(\operatorname{dom} f\) is convex.

</div>

<div class="theorem">

<strong>Theorem 2.1.2.</strong> Let \(f : \mathbb{R}^m \to [-\infty, \infty]\). Then \(f\) is convex if and only if for all \(x, y \in \operatorname{dom} f\) and \(\lambda \in (0,1)\),
\[ f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y). \]

</div>

![Epigraph of f(x)=x²](/pics/co463/epigraph.png)

![Convexity: chord above graph](/pics/co463/convex-function-def.png)

Lower semicontinuity is the natural continuity condition for functions taking values in \([-\infty, \infty]\): it says that the function cannot "jump down" at a limit point.

<div class="definition"><strong>Definition</strong> (Lower Semicontinuity). \(f\) is <strong>lower semicontinuous</strong> (l.s.c.) if \(\operatorname{epi} f\) is closed, equivalently if \(f(x) \leq \liminf_{x_n \to x} f(x_n)\) at every point.</div>

The equivalence between the two definitions — one geometric (closed epigraph) and one analytic (liminf condition) — is one of the many places where the epigraph viewpoint unifies disparate characterizations.

<div class="definition">

<strong>Definition 2.2.1</strong> (Lower Semicontinuity; Alternative). Let \(f : \mathbb{R}^n \to [-\infty, \infty]\) and \(x \in \mathbb{R}^n\). Then \(f\) is <strong>lower semicontinuous at \(x\)</strong> if for every sequence \((x_k) \to x\),
\[ f(x) \leq \liminf_{k} f(x_k). \]
We say \(f\) is l.s.c. if it is l.s.c. at every point.

</div>

<div class="theorem">

<strong>Theorem 2.2.1.</strong> Let \(C \subseteq \mathbb{R}^m\). The following hold:
<ol>
<li>\(C \neq \emptyset\) if and only if \(\delta_C\) is proper.</li>
<li>\(C\) is convex if and only if \(\delta_C\) is convex.</li>
<li>\(C\) is closed if and only if \(\delta_C\) is l.s.c.</li>
</ol>

</div>

Key examples: \(\delta_C\) (indicator function) is proper iff \(C \neq \emptyset\), convex iff \(C\) is convex, l.s.c. iff \(C\) is closed.

<div class="theorem"><strong>Proposition 2.2.2.</strong> The pointwise supremum \(F = \sup_{i \in I} f_i\) of a family of convex, l.s.c. functions is convex and l.s.c. (since \(\operatorname{epi} F = \bigcap_{i \in I} \operatorname{epi} f_i\)).</div>

### 2.2 The Support Function

The support function is a canonical tool for encoding the geometry of a convex set as a function — it records, for each direction \(u\), the maximum extent of the set in that direction.

<div class="definition"><strong>Definition</strong> (Support Function). For \(\emptyset \neq C \subseteq \mathbb{R}^n\), the <strong>support function</strong> is \(\sigma_C(u) = \sup_{c \in C} \langle c, u\rangle\).</div>

<div class="theorem">

<strong>Proposition 2.3.1.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^n\). Then \(\sigma_C\) is convex, l.s.c., and proper.

</div>

\(\sigma_C\) is always convex, l.s.c., and proper (it is a supremum of linear functions, which are affine hence convex). Crucially, \(\sigma_C\) determines \(C\) completely when \(C\) is closed and convex: the set \(C\) can be recovered as the intersection of the halfspaces \(\{\langle \cdot, u\rangle \leq \sigma_C(u)\}\) over all \(u\). This duality between convex sets and their support functions is the geometric heart of conjugate duality.

### 2.3 Further Notions of Convexity

For proper \(f\):

- **Strict convexity**: the Jensen inequality holds strictly for \(x \neq y\).
- **\(\beta\)-strong convexity** (constant \(\beta > 0\)): \(f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y) - \frac{\beta}{2}\lambda(1-\lambda)\|x-y\|^2\).

Strong \(\Rightarrow\) strict \(\Rightarrow\) convex. Equivalently, \(f\) is \(\beta\)-strongly convex iff \(f - \frac{\beta}{2}\|\cdot\|^2\) is convex.

![Strong convexity: quadratic lower bound](/pics/co463/strong-convexity.png)

A strongly convex, l.s.c., proper function has a **unique minimizer**.

### 2.4 Further Notions of Convexity and Sublevel Sets

<div class="definition"><strong>Definition</strong> (Sublevel Set). The <strong>\(c\)-sublevel set</strong> of \(f\) is \(\{x : f(x) \leq c\}\).</div>

Every sublevel set of a convex function is convex. Conversely, convexity of all sublevel sets is strictly weaker than convexity of \(f\) (such functions are called **quasiconvex**).

<div class="theorem">

<strong>Proposition 2.5.1.</strong> Let \(I\) be a finite index set and \((f_i)_{i \in I}\) a family of convex functions \(\mathbb{R}^m \to [-\infty, \infty]\). Then \(\sum_{i \in I} f_i\) is convex.

</div>

<div class="theorem">

<strong>Proposition 2.5.2.</strong> Let \(f\) be convex, l.s.c., proper and \(\lambda > 0\). Then \(\lambda f\) is convex and l.s.c.

</div>

![Sublevel sets of a convex function](/pics/co463/sublevel-set.png)

### 2.5 Minimizers

<div class="definition">

<strong>Definition 2.6.1</strong> (Global Minimizer). Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper and \(x \in \mathbb{R}^m\). Then \(x\) is a <strong>(global) minimizer</strong> of \(f\) if \(f(x) = \min f(\mathbb{R}^m)\). We write \(\operatorname{argmin} f\) for the set of minimizers.

</div>

<div class="definition">

<strong>Definition 2.6.2</strong> (Local Minimum). Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper. Then \(\bar{x}\) is a <strong>local minimum</strong> of \(f\) if there exists \(\delta > 0\) such that \(\|x - \bar{x}\| < \delta \Rightarrow f(\bar{x}) \leq f(x)\).

</div>

<div class="theorem"><strong>Proposition 2.6.1.</strong> For proper convex \(f\), every local minimizer is a global minimizer.</div>

<div class="proof"><strong>Proof.</strong> If \(x\) is a local minimizer with \(f(x) = \min_{B(x;\rho)} f\), take any \(y \in \operatorname{dom} f \setminus B(x;\rho)\). Set \(\lambda = 1 - \rho/\|x-y\|\) so that \(z = \lambda x + (1-\lambda)y \in B(x;\rho)\). By convexity: \(f(x) \leq f(z) \leq \lambda f(x) + (1-\lambda)f(y)\), giving \(f(x) \leq f(y)\). \(\square\)</div>

<div class="theorem">

<strong>Proposition 2.6.2.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper and convex, and \(C \subseteq \mathbb{R}^m\). If \(x\) minimizes \(f\) over \(C\) and \(x \in \operatorname{int} C\), then \(x\) is an (unconstrained) minimizer of \(f\).

</div>

<div class="theorem">

<strong>Theorem 2.12.1.</strong> Let \(f : \mathbb{R}^m \to \mathbb{R}\) be proper, l.s.c., and let \(C \subseteq \mathbb{R}^m\) be compact with \(C \cap \operatorname{dom} f \neq \emptyset\). Then:
<ol>
<li>\(f\) is bounded below over \(C\).</li>
<li>\(f\) attains its minimal value over \(C\).</li>
</ol>

</div>

<div class="definition">

<strong>Definition 2.12.1</strong> (Coercive Function). \(f : \mathbb{R}^m \to (-\infty, \infty]\) is <strong>coercive</strong> if \(\lim_{\|x\| \to \infty} f(x) = \infty\).

</div>

<div class="definition">

<strong>Definition 2.12.2</strong> (Super Coercive). \(f : \mathbb{R}^m \to (-\infty, \infty]\) is <strong>super coercive</strong> if \(\lim_{\|x\| \to \infty} \frac{f(x)}{\|x\|} = \infty\).

</div>

<div class="theorem">

<strong>Theorem 2.12.2.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper, l.s.c., and coercive, and \(C \subseteq \mathbb{R}^m\) closed with \(C \cap \operatorname{dom} f \neq \emptyset\). Then \(f\) attains its minimal value over \(C\).

</div>

**Existence via coercivity.** \(f\) is **coercive** if \(f(x) \to \infty\) as \(\|x\| \to \infty\). If \(f\) is proper, l.s.c., and coercive, it attains its minimum over any nonempty closed set (reducing to minimization over a compact ball).

### 2.6 Conjugate Functions and Fenchel Duality

Duality is one of the most profound ideas in convex analysis: every convex minimization problem has a "mirror" dual problem, and the relationship between primal and dual reveals structural information about both. The Fenchel conjugate is the analytic mechanism that makes this duality precise.

<div class="definition">
<strong>Definition</strong> (Fenchel–Legendre Conjugate). The <strong>convex conjugate</strong> of \(f : \mathbb{R}^n \to [-\infty, \infty]\) is
\[ f^*(u) := \sup_{x \in \mathbb{R}^n} \bigl(\langle u, x\rangle - f(x)\bigr). \]</div>

**Geometric interpretation.** Given slope \(u\), the conjugate \(f^*(u)\) is the best intercept \(\alpha\) such that the affine function \(\langle u, \cdot\rangle - \alpha\) is a global lower bound on \(f\). In other words, \(f^*\) records the tightest affine underestimate of \(f\) in every direction — a "dual" description of \(f\) through its supporting hyperplanes. The convex, l.s.c. epigraph of \(f\) is recovered as the intersection of all supporting halfspaces from below.

![Fenchel conjugate](/pics/co463/conjugate-function.png)

<div class="theorem"><strong>Proposition 2.7.1.</strong> For any \(f\), the conjugate \(f^*\) is convex and l.s.c. (as a supremum of affine functions).</div>

<div class="example">

<strong>Example 2.7.2.</strong> Let \(1 < p, q\) satisfy \(\frac{1}{p} + \frac{1}{q} = 1\). For \(f(x) := \frac{|x|^p}{p}\),
\[ f^*(u) = \frac{|u|^q}{q}. \]

</div>

<div class="example">

<strong>Example 2.7.3.</strong> For \(f(x) := e^x\),
\[ f^*(u) = \begin{cases} u \ln u - u, & u > 0 \\ 0, & u = 0 \\ \infty, & u < 0. \end{cases} \]

</div>

<div class="example">

<strong>Example 2.7.4.</strong> Let \(C \subseteq \mathbb{R}^m\). Then \(\delta_C^* = \sigma_C\). In other words, the conjugate of the indicator function of a set is its support function.

</div>

**Key examples:**
- \(f(x) = |x|^p/p\) \(\Rightarrow\) \(f^*(u) = |u|^q/q\) where \(1/p + 1/q = 1\).
- \(f(x) = e^x\) \(\Rightarrow\) \(f^*(u) = u\ln u - u\) for \(u > 0\), \(0\) for \(u = 0\), \(\infty\) for \(u < 0\).
- \(f = \delta_C\) \(\Rightarrow\) \(f^* = \sigma_C\) (indicator's conjugate is the support function).

<div class="theorem">
<strong>Proposition 2.11.2</strong> (Fenchel–Young Inequality). For proper \(f\) and any \(x, u \in \mathbb{R}^n\):
\[ f(x) + f^*(u) \geq \langle x, u\rangle. \]
Equality holds if and only if \(u \in \partial f(x)\).</div>

<div class="theorem"><strong>Theorem 2.11.5</strong> (Biconjugate). \(f\) is convex and l.s.c. if and only if \(f^{**} = f\). In this case, \(f^*\) is also proper, convex, and l.s.c.</div>

### 2.7 The Subdifferential Operator

For non-smooth convex functions, the gradient is replaced by the subdifferential. While a smooth function has a unique tangent plane at each point (its gradient), a non-smooth function like \(|x|\) can have many supporting hyperplanes at a kink — the subdifferential collects all of them.

<div class="definition">
<strong>Definition</strong> (Subdifferential). The <strong>subdifferential</strong> of proper \(f : \mathbb{R}^n \to (-\infty, \infty]\) is the set-valued operator
\[ \partial f(x) := \{u \in \mathbb{R}^n : \forall y \in \mathbb{R}^n,\; f(y) \geq f(x) + \langle u, y - x\rangle\}. \]
Elements \(u \in \partial f(x)\) are called <strong>subgradients</strong>.</div>

Geometrically, \(u\) is a subgradient at \(x\) if the affine function \(f(x) + \langle u, \cdot - x\rangle\) is a global supporting hyperplane to the graph of \(f\) from below. At smooth points, \(\partial f(x) = \{\nabla f(x)\}\) is a singleton; at kinks, it is an interval or convex set recording all supporting hyperplanes.

![Subdifferential of |x|](/pics/co463/subdifferential.png)

<div class="example">

<strong>Example 2.8.2.</strong> For \(f(x) = |x|\):
\[ \partial f(x) = \begin{cases} \{-1\}, & x < 0 \\ [-1,1], & x = 0 \\ \{1\}, & x > 0. \end{cases} \]

</div>

<div class="lemma">

<strong>Lemma 2.8.3.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper. Then \(\operatorname{dom} \partial f \subseteq \operatorname{dom} f\).

</div>

<div class="theorem">

<strong>Proposition 2.8.4.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^m\) be closed and convex. Then \(\partial \delta_C(x) = N_C(x)\).

</div>

**Connection to indicator functions.** \(\partial \delta_C(x) = N_C(x)\) for closed convex \(C\).

Fermat's rule for non-smooth functions is the fundamental optimality condition that generalizes \(\nabla f(x^*) = 0\) to the non-smooth setting.

<div class="theorem">
<strong>Theorem 2.8.1</strong> (Fermat's Rule). For proper \(f\):
\[ \operatorname{argmin} f = \{x : 0 \in \partial f(x)\} =: \operatorname{zer} \partial f. \]</div>

This is the non-smooth analogue of the first-order condition: \(x^*\) minimizes \(f\) if and only if \(0\) is a subgradient of \(f\) at \(x^*\) — meaning the zero affine function is a global underestimate of \(f - f(x^*)\). The elegance of this condition is that it unifies smooth and non-smooth optimality in a single framework.

<div class="theorem"><strong>Theorem 2.10.3.</strong> If \(f\) is convex, proper, and differentiable at \(x \in \operatorname{dom} f\), then \(\nabla f(x)\) is the <strong>unique</strong> subgradient of \(f\) at \(x\).</div>

<div class="definition">

<strong>Definition 2.10.1</strong> (Directional Derivative). Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper and \(x \in \operatorname{dom} f\). The <strong>directional derivative</strong> of \(f\) at \(x\) in direction \(d\) is
\[ f'(x; d) := \lim_{t \downarrow 0} \frac{f(x + td) - f(x)}{t}. \]

</div>

<div class="definition">

<strong>Definition 2.10.2</strong> (Differentiable). Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper and \(x \in \operatorname{dom} f\). Then \(f\) is <strong>differentiable at \(x\)</strong> if there is a linear operator \(\nabla f(x) : \mathbb{R}^m \to \mathbb{R}^m\) (the gradient) such that
\[ \lim_{\substack{y \to 0 \\ y \neq 0}} \frac{|f(x+y) - f(x) - \langle \nabla f(x), y\rangle|}{\|y\|} = 0. \]
When \(f\) is differentiable at \(x\), \(f'(x; d) = \langle \nabla f(x), d\rangle\).

</div>

<div class="theorem">

<strong>Theorem 2.10.1.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex with \(f(x) < \infty\). For each direction \(d\), the quotient \(\frac{f(x+\lambda d)-f(x)}{\lambda}\) is nondecreasing in \(\lambda > 0\). Hence \(f'(x; d)\) exists and
\[ f'(x; d) = \inf_{\lambda > 0} \frac{f(x + \lambda d) - f(x)}{\lambda}. \]

</div>

<div class="theorem">

<strong>Theorem 2.10.2.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex and proper, and \(x \in \operatorname{dom} f\). Then \(u \in \partial f(x)\) if and only if \(f'(x; d) \geq \langle u, d\rangle\) for all \(d \in \mathbb{R}^m\).

</div>

<div class="lemma">

<strong>Lemma 2.10.4.</strong> Let \(\varphi : \mathbb{R} \to (-\infty, \infty]\) be proper and differentiable on a nonempty interval \(I \subseteq \operatorname{dom} \varphi\). If \(\varphi'\) is increasing on \(I\), then \(\varphi\) is convex on \(I\).

</div>

<div class="theorem">

<strong>Proposition 2.10.5.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper, with \(\operatorname{dom} f\) open and convex, and \(f\) differentiable on \(\operatorname{dom} f\). The following are equivalent:
<ol>
<li>\(f\) is convex.</li>
<li>For all \(x, y \in \operatorname{dom} f\): \(f(x) \geq f(y) + \langle \nabla f(y), x - y\rangle\).</li>
<li>For all \(x, y \in \operatorname{dom} f\): \(\langle \nabla f(x) - \nabla f(y), x - y\rangle \geq 0\).</li>
</ol>

</div>

<div class="example">

<strong>Example 2.10.6.</strong> Let \(A\) be an \(m \times m\) matrix and \(f(x) = \langle x, Ax\rangle\). Then \(\nabla f(x) = (A + A^T)x\) and \(f\) is convex if and only if \(A + A^T\) is positive semidefinite.

</div>

**Directional derivatives.** For convex \(f\) with \(f(x) < \infty\), the directional derivative
\[ f'(x; d) := \lim_{t \downarrow 0} \frac{f(x + td) - f(x)}{t} = \inf_{t > 0} \frac{f(x+td) - f(x)}{t} \]
always exists, and \(u \in \partial f(x)\) iff \(f'(x; d) \geq \langle u, d\rangle\) for all \(d\).

### 2.8 Calculus of Subdifferentials

The fundamental question: when does \(\partial(f + g)(x) = \partial f(x) + \partial g(x)\)?

<div class="theorem">
<strong>Theorem 2.9.7</strong> (Sum Rule). Let \(f, g : \mathbb{R}^n \to (-\infty, \infty]\) be convex, l.s.c., proper with \(\operatorname{ri}\operatorname{dom} f \cap \operatorname{ri}\operatorname{dom} g \neq \emptyset\). Then for all \(x\):
\[ \partial(f + g)(x) = \partial f(x) + \partial g(x). \]</div>

<div class="definition">

<strong>Definition 2.9.1</strong> (Properly Separated). Let \(\emptyset \neq C_1, C_2 \subseteq \mathbb{R}^m\). Then \(C_1, C_2\) are <strong>properly separated</strong> if they are separated (i.e., \(\sup_{c_1 \in C_1}\langle b, c_1\rangle \leq \inf_{c_2 \in C_2}\langle b, c_2\rangle\) for some \(b \neq 0\)) and \(C_1 \cup C_2\) is not fully contained in the separating hyperplane.

</div>

<div class="theorem">

<strong>Proposition 2.9.2.</strong> Let \(\emptyset \neq C_1, C_2 \subseteq \mathbb{R}^m\) be convex. Then \(C_1, C_2\) are properly separated if and only if \(\operatorname{ri} C_1 \cap \operatorname{ri} C_2 = \emptyset\).

</div>

<div class="theorem">

<strong>Proposition 2.9.3.</strong> Let \(C_1, C_2 \subseteq \mathbb{R}^m\) be convex. Then
\[ \operatorname{ri}(C_1 + C_2) = \operatorname{ri} C_1 + \operatorname{ri} C_2. \]
Moreover, \(\operatorname{ri}(\lambda C) = \lambda(\operatorname{ri} C)\) for all \(\lambda \in \mathbb{R}\).

</div>

<div class="theorem">

<strong>Proposition 2.9.4.</strong> Let \(C_1 \subseteq \mathbb{R}^m\) and \(C_2 \subseteq \mathbb{R}^p\) be convex. Then \(\operatorname{ri}(C_1 \oplus C_2) = \operatorname{ri} C_1 \oplus \operatorname{ri} C_2\).

</div>

<div class="theorem">

<strong>Theorem 2.9.5.</strong> Let \(C_1, C_2 \subseteq \mathbb{R}^m\) be convex with \(\operatorname{ri} C_1 \cap \operatorname{ri} C_2 \neq \emptyset\). For each \(x \in C_1 \cap C_2\),
\[ N_{C_1 \cap C_2}(x) = N_{C_1}(x) + N_{C_2}(x). \]

</div>

<div class="theorem">

<strong>Proposition 2.9.6.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. For \(x, u \in \mathbb{R}^m\),
\[ u \in \partial f(x) \iff (u, -1) \in N_{\operatorname{epi} f}(x, f(x)). \]

</div>

The proof uses proper separation of epigraphs in \(\mathbb{R}^{n+2}\) and the normal cone sum formula \(N_{C_1 \cap C_2}(x) = N_{C_1}(x) + N_{C_2}(x)\) when \(\operatorname{ri} C_1 \cap \operatorname{ri} C_2 \neq \emptyset\).

**Constrained optimization reformulation.** Consider \(\min_{x \in C} f(x)\) with \(\operatorname{ri} C \cap \operatorname{ri}\operatorname{dom} f \neq \emptyset\). Since this equals \(\min f + \delta_C\) and \(\partial \delta_C = N_C\), the sum rule gives the optimality condition:
\[ \bar{x} \text{ solves } (P) \iff 0 \in \partial f(\bar{x}) + N_C(\bar{x}) \iff \partial f(\bar{x}) \cap (-N_C(\bar{x})) \neq \emptyset. \]

<div class="theorem"><strong>Proposition 2.9.1.</strong> For convex, l.s.c., proper \(f\): \(\emptyset \neq \operatorname{ri}\operatorname{dom} f \subseteq \operatorname{dom} \partial f\), and \(\overline{\operatorname{dom} f} = \overline{\operatorname{dom} \partial f}\).</div>

<div class="example">

<strong>Example 2.9.8.</strong> Let \(d \in \mathbb{R}^m\) and \(\emptyset \neq C \subseteq \mathbb{R}^m\) be closed and convex. Consider \(\min_{x \in C} \langle d, x\rangle\). Then \(\bar{x}\) solves this problem if and only if \(-d \in N_C(\bar{x})\).

</div>

**Subdifferential conjugacy.** For convex, l.s.c., proper \(f\):
\[ u \in \partial f(x) \iff x \in \partial f^*(u). \]
This is a powerful symmetry used in algorithmic duality.

### 2.9 Lipschitz Continuity and Second-Order Conditions

<div class="definition"><strong>Definition</strong> (Lipschitz). \(T : \mathbb{R}^n \to \mathbb{R}^n\) is \(L\)-Lipschitz if \(\|Tx - Ty\| \leq L\|x - y\|\) for all \(x, y\).</div>

<div class="theorem">
<strong>Lemma 2.13.3</strong> (Descent Lemma). Let \(f\) be convex and differentiable with \(\nabla f\) being \(L\)-Lipschitz on a convex domain. Then for all \(x, y\):
\[ f(y) \leq f(x) + \langle \nabla f(x), y - x\rangle + \frac{L}{2}\|x - y\|^2. \]</div>

<div class="proof"><strong>Proof.</strong> By the fundamental theorem of calculus and Cauchy–Schwarz: \(|f(y) - f(x) - \langle \nabla f(x), y - x\rangle| \leq \int_0^1 \|\nabla f(x + t(y-x)) - \nabla f(x)\|\|y-x\|\,dt \leq L\|x-y\|^2/2\). \(\square\)</div>

<div class="theorem"><strong>Theorem 2.13.4.</strong> For convex differentiable \(f\) and \(L > 0\), the following are equivalent: (i) \(\nabla f\) is \(L\)-Lipschitz; (ii) the descent lemma holds; (iii) \(f(y) \geq f(x) + \langle \nabla f(x), y - x\rangle + \frac{1}{2L}\|\nabla f(x) - \nabla f(y)\|^2\); (iv) \(\langle \nabla f(x) - \nabla f(y), x - y\rangle \geq \frac{1}{L}\|\nabla f(x) - \nabla f(y)\|^2\).</div>

For twice continuously differentiable \(f\): \(\nabla f\) is \(L\)-Lipschitz iff \(\|\nabla^2 f(x)\| \leq L\) everywhere; for PSD Hessians, this equals \(\lambda_{\max}(\nabla^2 f(x)) \leq L\).

<div class="example">

<strong>Example 2.13.1.</strong> Let \(f : \mathbb{R}^m \to \mathbb{R}\) be given by \(f(x) = \frac{1}{2}\langle x, Ax\rangle + \langle b, x\rangle + c\) where \(A \succeq 0\), \(b \in \mathbb{R}^m\), \(c \in \mathbb{R}\). Then:
<ol>
<li>\(\nabla f(x) = Ax + b\) for all \(x\).</li>
<li>\(\nabla f\) is Lipschitz with constant \(\|A\|\) (the operator norm of \(A\)).</li>
</ol>

</div>

<div class="example">

<strong>Example 2.13.2.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^m\) be closed and convex. Then \(P_C\) is Lipschitz continuous with constant \(1\).

</div>

<div class="theorem">

<strong>Theorem 2.13.7</strong> (Second Order Characterization). Let \(f : \mathbb{R}^m \to \mathbb{R}\) be twice continuously differentiable on \(\mathbb{R}^m\) and \(L \geq 0\). The following are equivalent:
<ol>
<li>\(\nabla f\) is \(L\)-Lipschitz.</li>
<li>For all \(x \in \mathbb{R}^m\), \(\|\nabla^2 f(x)\| \leq L\) (operator norm).</li>
</ol>

</div>

<div class="theorem">

<strong>Proposition 2.13.8.</strong> For a symmetric matrix \(A \in \mathbb{R}^{m \times m}\),
\[ \sup_{\|x\|=1} \|Ax\| = \max_{1 \leq i \leq m} |\lambda_i|, \]
where \(\lambda_i\) are the eigenvalues of \(A\).

</div>

<div class="theorem">

<strong>Proposition 2.13.9.</strong> A twice continuously differentiable function \(f : \mathbb{R}^m \to \mathbb{R}\) is convex if and only if \(\nabla^2 f(x)\) is positive semidefinite for all \(x\).

</div>

<div class="corollary">

<strong>Corollary 2.13.9.1.</strong> Let \(f : \mathbb{R}^m \to \mathbb{R}\) be convex and twice continuously differentiable, and \(L \geq 0\). Then \(\nabla f\) is \(L\)-Lipschitz if and only if \(\lambda_{\max}(\nabla^2 f(x)) \leq L\) for all \(x \in \mathbb{R}^m\).

</div>

<div class="example">

<strong>Example 2.13.10.</strong> Let \(f : \mathbb{R}^m \to \mathbb{R}\) be given by \(f(x) = \sqrt{1 + \|x\|^2}\). Then:
<ol>
<li>\(f\) is convex.</li>
<li>\(\nabla f\) is \(1\)-Lipschitz.</li>
</ol>

</div>

<div class="theorem">

<strong>Proposition 2.13.11.</strong> Let \(\beta > 0\). Then \(f : \mathbb{R}^m \to (-\infty, \infty]\) is \(\beta\)-strongly convex if and only if \(f - \frac{\beta}{2}\|\cdot\|^2\) is convex.

</div>

<div class="theorem">

<strong>Proposition 2.13.12.</strong> Let \(f, g : \mathbb{R}^m \to (-\infty, \infty]\) and \(\beta > 0\). Suppose \(f\) is \(\beta\)-strongly convex and \(g\) is convex. Then \(f + g\) is \(\beta\)-strongly convex.

</div>

<div class="theorem">

<strong>Proposition 2.13.13.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be strongly convex, l.s.c., and proper. Then \(f\) has a unique minimizer.

</div>

### 2.10 The Proximal Operator

The **proximal operator** is the workhorse of modern first-order algorithms, generalizing projection to arbitrary convex functions. Where the projection operator finds the nearest point in a convex set, the proximal operator finds the nearest point that also has a small function value — a regularized nearest-point problem.

<div class="definition">
<strong>Definition</strong> (Proximal Operator). For convex, l.s.c., proper \(f\):
\[ \operatorname{Prox}_f(x) := \operatorname{argmin}_{u \in \mathbb{R}^n}\Bigl\{f(u) + \tfrac{1}{2}\|u - x\|^2\Bigr\}. \]</div>

The proximal operator interpolates between the identity map (when \(f = 0\)) and the projection onto a convex set (when \(f = \delta_C\)). For a general convex function, it moves from \(x\) towards the minimizer of \(f\), with the quadratic term preventing too large a step.

<div class="theorem"><strong>Theorem 2.14.1.</strong> For convex, l.s.c., proper \(f\), \(\operatorname{Prox}_f(x)\) is always a singleton (the regularization \(f(u) + \frac{1}{2}\|u-x\|^2\) is strongly convex, hence has a unique minimizer).</div>

This tells us that the proximal operator is a well-defined function — not just a set-valued map — because the \(\frac{1}{2}\|u-x\|^2\) term breaks ties by selecting the unique closest minimizer.

<div class="theorem">

<strong>Proposition 2.14.3.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. Let \(x, p \in \mathbb{R}^m\). Then \(p = \operatorname{Prox}_f(x)\) if and only if for all \(y \in \mathbb{R}^m\),
\[ \langle y - p, x - p\rangle + f(p) \leq f(y). \]
Equivalently, \(x - p \in \partial f(p)\), i.e., \(p = (\operatorname{Id} + \partial f)^{-1}(x)\).

</div>

<div class="example">

<strong>Example 2.14.2.</strong> For \(\emptyset \neq C \subseteq \mathbb{R}^m\) closed and convex, \(\operatorname{Prox}_{\delta_C} = P_C\). That is, the proximal operator of the indicator function is the projection.

</div>

<div class="example">

<strong>Example 2.14.4.</strong> For \(f(x) = |x|\),
\[ \operatorname{Prox}_f(x) = \begin{cases} x - 1, & x > 1 \\ 0, & x \in [-1, 1] \\ x + 1, & x < -1. \end{cases} \]

</div>

<div class="example">

<strong>Example 2.14.6.</strong> Convexity is crucial for the proximal operator to be well-defined (singleton-valued). For a non-convex function such as \(h(x) = 0\) for \(x \neq 0\) and \(h(0) = -\lambda\), the proximal operator can be empty-valued.

</div>

<div class="example">

<strong>Example 2.14.7</strong> (Soft Threshold). For \(f(x) = \lambda|x|\) (\(\lambda \geq 0\)),
\[ \operatorname{Prox}_f(x) = \operatorname{sign}(x)(|x| - \lambda)_+ := \begin{cases} x - \lambda, & x > \lambda \\ 0, & x \in [-\lambda, \lambda] \\ x + \lambda, & x < -\lambda. \end{cases} \]

</div>

<div class="example">

<strong>Example 2.14.9.</strong> Let \(g : \mathbb{R}^m \to (-\infty, \infty]\) be given by \(g(x) = -\alpha \sum_{i=1}^m \log x_i\) for \(x > 0\) (and \(\infty\) otherwise), where \(\alpha > 0\). Then
\[ \operatorname{Prox}_g(x)_i = \frac{x_i + \sqrt{x_i^2 + 4\alpha}}{2}. \]

</div>

<div class="theorem">

<strong>Theorem 2.14.10.</strong> Let \(g : \mathbb{R}^m \to (-\infty, \infty]\) be proper, \(c > 0\), \(a \in \mathbb{R}^m\), \(\gamma \in \mathbb{R}\). Define
\[ f(x) = g(x) + \frac{c}{2}\|x\|^2 + \langle a, x\rangle + \gamma. \]
Then for all \(x \in \mathbb{R}^m\),
\[ \operatorname{Prox}_f(x) = \operatorname{Prox}_{\frac{1}{c+1}g}\!\left(\frac{x - a}{c+1}\right). \]

</div>

<div class="example">

<strong>Example 2.14.11.</strong> Let \(\mu \in \mathbb{R}\), \(\alpha \geq 0\), and \(f(x) = \mu x + \delta_{[0,\alpha]}(x)\). Then
\[ \operatorname{Prox}_f(x) = \min(\max(x - \mu, 0), \alpha). \]

</div>

<div class="theorem">

<strong>Theorem 2.14.12.</strong> Let \(g : \mathbb{R} \to (-\infty, \infty]\) be convex, l.s.c., and proper with \(\operatorname{dom} g \subseteq [0,\infty)\), and let \(f(x) = g(\|x\|)\). Then for \(x \neq 0\),
\[ \operatorname{Prox}_f(x) = \operatorname{Prox}_g(\|x\|) \cdot \frac{x}{\|x\|}, \]
and for \(x = 0\), \(\operatorname{Prox}_f(0) = \{u \in \mathbb{R}^m : \|u\| = \operatorname{Prox}_g(0)\}\).

</div>

<div class="example">

<strong>Example 2.14.13.</strong> Let \(\alpha > 0\), \(\lambda \geq 0\), and \(f(x) = \lambda|x|\) for \(|x| \leq \alpha\) (and \(\infty\) otherwise). Then
\[ \operatorname{Prox}_f(x) = \min(\max(|x| - \lambda, 0), \alpha)\,\operatorname{sgn}(x). \]

</div>

<div class="example">

<strong>Example 2.14.14.</strong> Let \(w, \alpha \in \mathbb{R}^m_+\) and \(f(x) = \sum_{i=1}^m w_i |x_i|\) for \(-\alpha \leq x \leq \alpha\) (and \(\infty\) otherwise). Then
\[ \operatorname{Prox}_f(x)_i = \min(\max(|x_i| - w_i, 0), \alpha_i)\,\operatorname{sgn}(x_i). \]

</div>

**Characterization.** \(p = \operatorname{Prox}_f(x)\) iff for all \(y \in \mathbb{R}^n\):
\[ \langle y - p, x - p\rangle + f(p) \leq f(y), \]
equivalently \(x - p \in \partial f(p)\), i.e., \(p = (\operatorname{Id} + \partial f)^{-1}(x)\).

**Key examples:**
- \(f = \delta_C\): \(\operatorname{Prox}_{\delta_C} = P_C\) (projection is the special case).
- \(f(x) = |x|\): soft-thresholding \(\operatorname{Prox}_f(x) = \operatorname{sign}(x)(|x|-1)_+\).
- \(f(x) = \lambda|x|\): \(\operatorname{Prox}_f(x) = \operatorname{sign}(x)(|x|-\lambda)_+ =: S_\lambda(x)\).

<div class="theorem"><strong>Theorem 2.14.8</strong> (Separability). If \(f(x) = \sum_{i=1}^m f_i(x_i)\) for convex, l.s.c., proper \(f_i\), then \(\operatorname{Prox}_f(x) = (\operatorname{Prox}_{f_i}(x_i))_{i=1}^m\) componentwise.</div>

<div class="theorem"><strong>Proposition 2.14.5.</strong> \(x = \operatorname{Prox}_f(x)\) iff \(x \in \operatorname{argmin} f\) (fixed points of the proximal operator are minimizers).</div>

### 2.11 Nonexpansive and Averaged Operators

The convergence theory for iterative algorithms rests on the notion of nonexpansive operators — maps that never increase distances. Understanding which operators are nonexpansive (or the stronger "firmly nonexpansive") is the key to proving convergence.

<div class="definition">
<strong>Definitions.</strong>
<ul>
<li>\(T : \mathbb{R}^n \to \mathbb{R}^n\) is <strong>nonexpansive</strong> if \(\|Tx - Ty\| \leq \|x - y\|\).</li>
<li>\(T\) is <strong>firmly nonexpansive (f.n.e.)</strong> if \(\|Tx - Ty\|^2 + \|(I-T)x - (I-T)y\|^2 \leq \|x - y\|^2\), equivalently \(\|Tx - Ty\|^2 \leq \langle x - y, Tx - Ty\rangle\).</li>
<li>\(T\) is <strong>\(\alpha\)-averaged</strong> (\(\alpha \in (0,1)\)) if \(T = (1-\alpha)\operatorname{Id} + \alpha N\) for some nonexpansive \(N\).</li>
</ul></div>

<div class="definition">

<strong>Definition 2.15.4</strong> (Fixed Point). Let \(T : \mathbb{R}^m \to \mathbb{R}^m\). The <strong>fixed point set</strong> of \(T\) is
\[ \operatorname{Fix} T := \{x \in \mathbb{R}^m : x = Tx\}. \]

</div>

<div class="theorem">

<strong>Proposition 2.15.1.</strong> Let \(T : \mathbb{R}^m \to \mathbb{R}^m\). The following are equivalent:
<ol>
<li>\(T\) is firmly nonexpansive.</li>
<li>\(\operatorname{Id} - T\) is firmly nonexpansive.</li>
<li>\(2T - \operatorname{Id}\) is nonexpansive.</li>
<li>For all \(x, y\): \(\|Tx - Ty\|^2 \leq \langle x - y, Tx - Ty\rangle\).</li>
<li>For all \(x, y\): \(\langle Tx - Ty, (\operatorname{Id}-T)x - (\operatorname{Id}-T)y\rangle \geq 0\).</li>
</ol>
In particular, \(T\) is f.n.e. if and only if it is \(\frac{1}{2}\)-averaged.

</div>

<div class="theorem">

<strong>Proposition 2.15.2.</strong> Let \(T : \mathbb{R}^m \to \mathbb{R}^m\) be linear. The following are equivalent:
<ol>
<li>\(T\) is f.n.e.</li>
<li>\(\|2T - \operatorname{Id}\| \leq 1\).</li>
<li>For all \(x\): \(\|Tx\|^2 \leq \langle x, Tx\rangle\).</li>
<li>For all \(x\): \(\langle Tx, x - Tx\rangle \geq 0\).</li>
</ol>

</div>

<div class="example">

<strong>Example 2.15.3.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^m\) be convex and closed. Then \(P_C\) is firmly nonexpansive: for all \(x, y \in \mathbb{R}^m\), \(\|P_C(x) - P_C(y)\|^2 \leq \langle P_C(x) - P_C(y), x - y\rangle\).

</div>

<div class="example">

<strong>Example 2.15.4.</strong> \(T = -\frac{1}{2}\operatorname{Id}\) is averaged (specifically, \(\frac{3}{4}\)-averaged via \(T = \frac{1}{4}\operatorname{Id} + \frac{3}{4}(-\operatorname{Id})\)) but NOT firmly nonexpansive.

</div>

<div class="example">

<strong>Example 2.15.5.</strong> \(T = -\operatorname{Id}\) is nonexpansive but NOT averaged. Indeed, writing \(-\operatorname{Id} = (1-\alpha)\operatorname{Id} + \alpha N\) for nonexpansive \(N\) would require \(\|N\| = \frac{2-\alpha}{\alpha} > 1\) for any \(\alpha \in (0,1)\).

</div>

<div class="theorem">

<strong>Proposition 2.15.6.</strong> Let \(T : \mathbb{R}^m \to \mathbb{R}^m\) be nonexpansive. Then \(T\) is continuous.

</div>

The hierarchy firm nonexpansive \(\Rightarrow\) averaged \(\Rightarrow\) nonexpansive is strict at each step. Firm nonexpansiveness is the "just right" condition for convergence: strong enough to guarantee convergence to a fixed point, but weak enough to include the proximal operator and the projection. Firm nonexpansiveness \(\Leftrightarrow\) \(\frac{1}{2}\)-averaged \(\Leftrightarrow\) \(2T - \operatorname{Id}\) is nonexpansive.

<div class="theorem"><strong>Proposition 2.16.7.</strong> \(\operatorname{Prox}_f\) is firmly nonexpansive. In particular, \(P_C\) is firmly nonexpansive.</div>

### 2.12 Féjer Monotonicity and Convergence

Féjer monotonicity is a powerful convergence criterion: a sequence converging toward a target set in the sense that it never moves farther from any target point. This "monotone approach" property, together with a cluster point condition, guarantees full convergence.

<div class="definition"><strong>Definition</strong> (Féjer Monotone). A sequence \((x_n)\) is <strong>Féjer monotone</strong> with respect to \(C\) if \(\|x_{n+1} - c\| \leq \|x_n - c\|\) for all \(c \in C\), \(n \in \mathbb{N}\).</div>

<div class="example">

<strong>Example 2.16.1.</strong> Suppose \(\operatorname{Fix} T \neq \emptyset\) for some nonexpansive \(T : \mathbb{R}^m \to \mathbb{R}^m\). For any \(x_0 \in \mathbb{R}^m\), the sequence defined recursively by \(x_n := T(x_{n-1})\) is Féjer monotone with respect to \(\operatorname{Fix} T\).

</div>

<div class="theorem">

<strong>Proposition 2.16.2.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^m\) and \((x_n)_{n \geq 0}\) be a Féjer monotone sequence with respect to \(C\). The following hold:
<ol>
<li>\((x_n)\) is bounded.</li>
<li>For every \(c \in C\), \((\|x_n - c\|)_{n \geq 0}\) converges.</li>
<li>\((d_C(x_n))_{n \geq 0}\) is decreasing and converges.</li>
</ol>

</div>

Féjer-monotone sequences are automatically bounded (since all points stay in the closed ball around the starting point) and have converging distance sequences (since \(d(x_n, C)\) is monotone and bounded below by 0).

<div class="theorem">

<strong>Proposition 2.16.3.</strong> A bounded sequence \((x_n)_{n \in \mathbb{N}}\) in \(\mathbb{R}^m\) converges if and only if it has a unique cluster point.

</div>

<div class="lemma">

<strong>Lemma 2.16.4.</strong> Let \((x_n)_{n \in \mathbb{N}}\) be a sequence in \(\mathbb{R}^m\) and \(\emptyset \neq C \subseteq \mathbb{R}^m\) such that for all \(c \in C\), the sequence \((\|x_n - c\|)_{n \in \mathbb{N}}\) converges, and every cluster point of \((x_n)\) lies in \(C\). Then \((x_n)\) converges to a point in \(C\).

</div>

<div class="theorem"><strong>Theorem 2.16.5.</strong> If \((x_n)\) is Féjer monotone w.r.t. \(C\) and every cluster point lies in \(C\), then \((x_n)\) converges to a point in \(C\).</div>

<div class="theorem">
<strong>Theorem 2.16.6.</strong> Let \(T\) be \(\alpha\)-averaged with \(\operatorname{Fix} T \neq \emptyset\). The iteration \(x_{n+1} = Tx_n\) satisfies:
<ol>
<li>\((x_n)\) is Féjer monotone w.r.t. \(\operatorname{Fix} T\).</li>
<li>\(Tx_n - x_n \to 0\).</li>
<li>\(x_n\) converges to a point in \(\operatorname{Fix} T\).</li>
</ol></div>

<div class="corollary">

<strong>Corollary 2.16.6.1.</strong> Let \(T : \mathbb{R}^m \to \mathbb{R}^m\) be firmly nonexpansive with \(\operatorname{Fix} T \neq \emptyset\). Put \(x_0 \in \mathbb{R}^m\) and define \(x_{n+1} := Tx_n\) recursively. Then there exists \(\bar{x} \in \operatorname{Fix} T\) such that \(x_n \to \bar{x}\).

</div>

<div class="corollary">

<strong>Corollary 2.16.7.1.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper with \(\operatorname{argmin} f \neq \emptyset\). Let \(x_0 \in \mathbb{R}^m\) with \(x_{n+1} := \operatorname{Prox}_f(x_n)\). Then there exists \(\bar{x} \in \operatorname{argmin} f\) such that \(x_n \to \bar{x}\).

</div>

**Composition of averaged operators.** If \(T_1\) is \(\alpha_1\)-averaged and \(T_2\) is \(\alpha_2\)-averaged, then \(T_1 T_2\) is \(\alpha\)-averaged with \(\alpha = \frac{\alpha_1 + \alpha_2 - 2\alpha_1\alpha_2}{1 - \alpha_1\alpha_2}\).

<div class="theorem">

<strong>Proposition 2.17.1.</strong> Let \(T : \mathbb{R}^m \to \mathbb{R}^m\) be nonexpansive and \(\alpha \in (0,1)\). The following are equivalent:
<ol>
<li>\(T\) is \(\alpha\)-averaged.</li>
<li>\(\left(1 - \frac{1}{\alpha}\right)\operatorname{Id} + \frac{1}{\alpha}T\) is nonexpansive.</li>
<li>For each \(x, y \in \mathbb{R}^m\): \(\|Tx - Ty\|^2 \leq \|x - y\|^2 - \frac{1-\alpha}{\alpha}\|({\operatorname{Id}} - T)x - (\operatorname{Id} - T)y\|^2\).</li>
</ol>

</div>

## Chapter 3: Conjugate Functions and Duality

The conjugate function, introduced in Chapter 2 as a tool for studying individual functions, now takes center stage as the mechanism for constructing dual problems. Chapter 3 shows that every convex minimization problem has a "dual" formulation — obtained by conjugating the objective and constraints — and that strong duality (primal equals dual optimal value) holds under mild regularity conditions.

### 3.1 Conjugacy and the Biconjugate Theorem

We have already introduced the Fenchel conjugate \(f^*\) in Chapter 2. Let us now collect the key conjugacy results, culminating in the biconjugate theorem — which says that the double conjugate of a convex l.s.c. function recovers the original function exactly.

<div class="theorem">

<strong>Proposition 2.11.1.</strong> Let \(f, g : \mathbb{R}^m \to [-\infty, \infty]\). Then:
<ol>
<li>\(f^{**} := (f^*)^* \leq f\) always.</li>
<li>\(f \leq g \Rightarrow f^* \geq g^*\) and \(f^{**} \leq g^{**}\) (conjugation reverses order).</li>
</ol>

</div>

<div class="theorem">

<strong>Proposition 2.11.3.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex and proper. For \(x, u \in \mathbb{R}^m\),
\[ u \in \partial f(x) \iff f(x) + f^*(u) = \langle x, u\rangle. \]

</div>

<div class="theorem">

<strong>Proposition 2.11.4.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex and proper. If \(\partial f(x) \neq \emptyset\) for some \(x\), then \(f^{**}(x) = f(x)\).

</div>

<div class="theorem">

<strong>Proposition 2.11.5.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper. Then \(f\) is convex and l.s.c. if and only if \(f = f^{**}\). In this case, \(f^*\) is also proper.

</div>

<div class="corollary">

<strong>Corollary 2.11.5.1.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. Then:
<ol>
<li>\(f^*\) is convex, l.s.c., and proper.</li>
<li>\(f^{**} = f\).</li>
</ol>

</div>

<div class="theorem">

<strong>Proposition 2.11.6.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. Then
\[ u \in \partial f(x) \iff x \in \partial f^*(u). \]

</div>

<div class="theorem">
<strong>Properties of Conjugates.</strong>
<ol>
<li>\(f^{**} \leq f\) always.</li>
<li>\(f \leq g \Rightarrow f^* \geq g^*\) (conjugation reverses order).</li>
<li>If \(f\) is convex and l.s.c., \(f^{**} = f\) (the biconjugate theorem).</li>
<li>For convex, l.s.c., proper \(f\): \(u \in \partial f(x) \Leftrightarrow f(x) + f^*(u) = \langle x, u\rangle \Leftrightarrow x \in \partial f^*(u)\).</li>
</ol></div>

### 3.2 Fenchel Duality

Consider the primal problem \((P)\): \(\min_{x \in \mathbb{R}^n} f(x) + g(x)\) with \(f, g\) convex, l.s.c., proper. Introduce a splitting \(x = z\) and a Lagrange multiplier \(y\):
\[ L(x, z; y) = f(x) + g(z) + \langle y, z - x\rangle. \]
The **dual function** is \(d(u) = \inf_{x,z} L(x,z;u) = -f^*(u) - g^*(-u)\). Setting \(p = \inf(f + g)\) and \(d^* = \inf(f^* + g^*(\cdot \circ (-\operatorname{Id})))\), **weak duality** gives \(p \geq -d^*\).

### 3.3 Fenchel–Rockafellar Duality

For the problem \(\min_{x} f(x) + g(Ax)\) (\(A \in \mathbb{R}^{m \times n}\)), the Fenchel–Rockafellar dual is:
\[ (D): \quad \min_{y \in \mathbb{R}^m} f^*(-A^T y) + g^*(y). \]
Strong duality holds (primal = dual optimal values) under regularity conditions such as \(\operatorname{ri}(\operatorname{dom} f) \cap A^{-1}(\operatorname{ri}(\operatorname{dom} g)) \neq \emptyset\).

## Chapter 4: Optimality Conditions and Subdifferentials

With the theory of subdifferentials and duality established, Chapter 4 translates these tools into concrete optimality conditions for constrained problems. The subdifferential sum rule, the KKT conditions, and the normal cone characterization are all facets of the same underlying principle: at a minimizer, no feasible descent direction exists.

### 4.1 Optimality for Constrained Problems

Consider the constrained problem \(\min_{x \in C} f(x)\) with \(f\) convex, l.s.c., proper and \(C\) closed convex. Encoding the constraint as \(\min f + \delta_C\) and applying the sum rule brings us to a clean characterization of optimality in terms of normal cones.

<div class="theorem">
<strong>Theorem.</strong> If \(\operatorname{ri} C \cap \operatorname{ri}\operatorname{dom} f \neq \emptyset\), then \(\bar{x}\) solves \((P)\) iff
\[ \partial f(\bar{x}) \cap (-N_C(\bar{x})) \neq \emptyset, \]
i.e., there exists a "negative subgradient" that is a normal vector to \(C\) at \(\bar{x}\).</div>

### 4.2 Smooth + Non-smooth Optimality

<div class="theorem">
<strong>Theorem 3.1.1.</strong> Let \(f\) be proper and \(g\) be convex, l.s.c., proper with \(\operatorname{dom} g \subseteq \operatorname{int}(\operatorname{dom} f)\). Consider \(\min f(x) + g(x)\).
<ol>
<li>If \(f\) is differentiable at a local minimum \(x^*\), then \(-\nabla f(x^*) \in \partial g(x^*)\).</li>
<li>If additionally \(f\) is convex, then \(x^*\) is global iff \(-\nabla f(x^*) \in \partial g(x^*)\).</li>
</ol></div>

### 4.3 KKT Conditions

The KKT conditions are the central tool of constrained optimization theory: they give necessary and, under convexity, sufficient conditions for a point to solve a constrained minimization problem. Their power lies in converting a constrained problem into an unconstrained system of equations and inequalities.

<div class="theorem">
<strong>Theorem 3.1.4</strong> (Fritz–John). If \(x^*\) solves the problem, there exist multipliers \(\alpha_0, \ldots, \alpha_n \geq 0\) (not all zero) such that:
\[ 0 \in \alpha_0 \partial f(x^*) + \sum_{i=1}^n \alpha_i \partial g_i(x^*), \qquad \alpha_i g_i(x^*) = 0 \;\forall i. \]</div>

The Fritz-John conditions follow from a key lemma. Setting \(F(x) := \max\{f(x) - \mu, g_1(x), \ldots, g_n(x)\}\) where \(\mu\) is the optimal value:

<div class="lemma">

<strong>Lemma 3.1.2.</strong> For all \(x \in \mathbb{R}^m\), \(F(x) \geq 0\). Moreover, the solutions of \((P)\) are precisely the minimizers of \(F\), i.e., \(\{x : F(x) = 0\}\).

</div>

The Fritz-John conditions are a weaker form that does not guarantee \(\alpha_0 > 0\): the objective function might be multiplied by zero, yielding degenerate conditions. Slater's constraint qualification rules this out.

<div class="theorem">
<strong>Theorem 3.1.5</strong> (KKT Necessary Conditions). Under Slater's condition (existence of strictly feasible \(s\) with \(g_i(s) < 0\) for all \(i\)), \(\alpha_0 > 0\) can be guaranteed, yielding multipliers \(\lambda_i = \alpha_i/\alpha_0 \geq 0\) and:
\[ 0 \in \partial f(x^*) + \sum_i \lambda_i \partial g_i(x^*), \qquad \lambda_i g_i(x^*) = 0. \]</div>

<div class="theorem"><strong>Theorem 3.1.6</strong> (KKT Sufficient Conditions). If primal feasibility, dual feasibility (\(\lambda_i \geq 0\)), stationarity (\(0 \in \partial f(x^*) + \sum_i \lambda_i \partial g_i(x^*)\)), and complementary slackness (\(\lambda_i g_i(x^*) = 0\)) all hold, then \(x^*\) solves the problem.</div>

The sufficiency theorem completes the picture: for convex problems, the KKT conditions are not just necessary but also sufficient for global optimality. This is in sharp contrast to the nonconvex setting, where KKT points can be saddle points or local maxima.

**Max rule for subdifferentials.** For \(g(x) = \max\{g_1(x), \ldots, g_n(x)\}\) with \(x \in \bigcap \operatorname{int}\operatorname{dom} g_i\):
\[ \partial g(x) = \operatorname{conv}\Bigl\{\partial g_i(x) : i \in A(x)\Bigr\}, \quad A(x) = \{i : g_i(x) = g(x)\}. \]

## Chapter 5: Algorithms for Convex Optimization

Having developed the theory of convex functions, subdifferentials, and optimality conditions, we now turn to algorithms. Chapter 5 presents a hierarchy of methods — from simple gradient descent to accelerated proximal algorithms — each suited to a different setting determined by the smoothness and structure of the objective.

### 5.1 Gradient Descent

For smooth unconstrained minimization \(\min_{x \in \mathbb{R}^n} f(x)\) with \(f\) differentiable, the simplest algorithm is gradient descent: repeatedly move in the direction of steepest descent.

<div class="definition">

<strong>Definition 3.2.1</strong> (Descent Direction). Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be proper and \(x \in \operatorname{int}\operatorname{dom} f\). A vector \(d \in \mathbb{R}^m \setminus \{0\}\) is a <strong>descent direction</strong> of \(f\) at \(x\) if the directional derivative satisfies \(f'(x; d) < 0\).

</div>

If \(0 \neq \nabla f(x)\) exists, then \(-\nabla f(x)\) is a descent direction, since \(f'(x; -\nabla f(x)) = -\|\nabla f(x)\|^2 < 0\).

**Algorithm.** Initialize \(x_0\). Update \(x_{n+1} = x_n - t_n \nabla f(x_n)\) where \(t_n := \operatorname{argmin}_{t \geq 0} f(x_n - t\nabla f(x_n))\) (exact line search) or a fixed step size \(1/L\).

<div class="theorem">

<strong>Theorem 3.2.1</strong> (Peressini, Sullivan, Uhl). If \(f\) is strictly convex and coercive, then the gradient descent iterates \(x_n\) converge to the unique minimizer of \(f\).

</div>

For **non-smooth** functions, the negative subgradient is not necessarily a descent direction — a key pathology that motivates the subgradient method instead.

<div class="example">

<strong>Example 3.2.3</strong> (Wolfe). Let \(\gamma > 1\). Define \(f : \mathbb{R}^2 \to \mathbb{R}\) by
\[ f(x_1, x_2) = \begin{cases} \sqrt{x_1^2 + \gamma x_2^2} & |x_2| \leq x_1 \\ x_1 + \frac{\gamma |x_2|}{\sqrt{1+\gamma}} & \text{else} \end{cases} \]
Then \(f\) is convex and differentiable on \(\mathbb{R}^2 \setminus ((-\infty, 0] \times \{0\})\), yet the steepest descent method starting from \(x_0 = (\gamma, 1)\) generates iterates \(x_n \to (0, 0)\), which is <strong>not</strong> a minimizer of \(f\) (in fact \(\operatorname{argmin} f = \emptyset\)).

</div>

### 5.2 Projected Subgradient Method

For \(\min_{x \in C} f(x)\) with \(C \subseteq \operatorname{int}\operatorname{dom} f\) and bounded subgradients \(\sup_{c \in C}\|\partial f(c)\| \leq L < \infty\):

**Algorithm.**
1. Initialize \(x_0 \in C\).
2. Pick subgradient \(f'(x_n) \in \partial f(x_n)\), step size \(t_n > 0\).
3. Update \(x_{n+1} = P_C(x_n - t_n f'(x_n))\).

<div class="lemma">

<strong>Lemma 3.3.1.</strong> Let \(s \in S := \operatorname{argmin}_{x \in C} f(x)\). Then
\[ \|x_{n+1} - s\|^2 \leq \|x_n - s\|^2 - 2t_n(f(x_n) - \mu) + t_n^2 \|f'(x_n)\|^2. \]

</div>

<div class="definition"><strong>Definition</strong> (Polyak's Step Size). \(t_n = \frac{f(x_n) - \mu}{\|f'(x_n)\|^2}\) where \(\mu = \min_{C} f\) (requires knowing \(\mu\)).</div>

<div class="theorem">
<strong>Theorem 3.3.2</strong> (Convergence). With Polyak's step size:
<ol>
<li>\((x_n)\) is Féjer monotone w.r.t. \(S = \operatorname{argmin}_C f\).</li>
<li>\(f(x_n) \to \mu\).</li>
<li>\(\mu_n - \mu \leq \frac{L \cdot d_S(x_0)}{\sqrt{n+1}}\) where \(\mu_n = \min_{0 \leq k \leq n} f(x_k)\).</li>
<li>\(x_n \to s \in S\).</li>
</ol></div>

<div class="theorem">

<strong>Theorem 3.3.3</strong> (Convergence of Projected Subgradient). Suppose \(x_n\) is generated by the projected subgradient method with Polyak's rule. Then \(x_n \to s \in S\).

</div>

<div class="example">

<strong>Example 3.3.4.</strong> Let \(\emptyset \neq C \subseteq \mathbb{R}^m\) be convex and closed. Then for fixed \(x \in \mathbb{R}^m\):
\[ \partial d_C(x) = \begin{cases} \dfrac{x - P_C(x)}{d_C(x)} & x \notin C \\ N_C(x) \cap B(0; 1) & x \in C \end{cases} \]
In particular, \(\sup\|\partial d_C(x)\| \leq 1\).

</div>

<div class="lemma">

<strong>Lemma 3.3.5.</strong> Let \(f\) be convex, l.s.c., and proper. Fix \(\lambda > 0\). Then \(\partial(\lambda f) = \lambda \partial f\).

</div>

**Convergence rate.** The subgradient method achieves \(O(1/\sqrt{n})\) convergence in function value — significantly slower than gradient descent's \(O(1/n)\) under smoothness.

**Application: Convex Feasibility.** To find a point in \(\bigcap_{i=1}^k S_i\), minimize \(f(x) = \max_i d_{S_i}(x)\). The projected subgradient step simplifies to: find the most violated constraint \(S_{\bar{\imath}}\) and project: \(x_{n+1} = P_{S_{\bar\imath}}(x_n)\) — this is the **alternating projections** algorithm.

### 5.3 Proximal Gradient Method (PGM)

Many important problems — including LASSO regression, basis pursuit, and sparse signal recovery — have a composite objective: a smooth term plus a non-smooth regularizer. The proximal gradient method handles this structure by applying gradient descent to the smooth part and the proximal operator to the non-smooth part in alternation.

For the composite problem \(\min_{x} F(x) := f(x) + g(x)\) where:
- \(f\) is convex, l.s.c., differentiable with \(L\)-Lipschitz gradient,
- \(g\) is convex, l.s.c., proper with \(\operatorname{dom} g \subseteq \operatorname{int}\operatorname{dom} f\).

**Update operator.** Define \(T = \operatorname{Prox}_{g/L}\bigl(\operatorname{Id} - \frac{1}{L}\nabla f\bigr)\). Fixed points of \(T\) are exactly the minimizers of \(F\):

<div class="theorem">

<strong>Theorem 3.4.2.</strong> For \(x \in \mathbb{R}^m\):
\[ x \in S = \operatorname{argmin} F \iff x = Tx \iff x \in \operatorname{Fix} T. \]

</div>

<div class="theorem">

<strong>Proposition 3.4.3.</strong> Let \(f : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. Fix \(\beta > 0\). Then \(f\) is \(\beta\)-strongly convex if and only if for all \(x \in \operatorname{dom}\partial f\) and \(u \in \partial f(x)\):
\[ f(y) \geq f(x) + \langle u, y - x\rangle + \frac{\beta}{2}\|y - x\|^2 \qquad \forall y. \]

</div>

<div class="theorem">

<strong>Proposition 3.4.4</strong> (Proximal-Gradient Inequality). Let \(x \in \mathbb{R}^m\), \(y \in \operatorname{int}\operatorname{dom} f\), and \(y^+ := \operatorname{Prox}_{g/L}(y - \frac{1}{L}\nabla f(y)) = Ty\). Then
\[ F(x) - F(y^+) \geq \frac{L}{2}\|x - y^+\|^2 - \frac{L}{2}\|x - y\|^2 + D_f(x, y), \]
where \(D_f(x, y) := f(x) - f(y) - \langle \nabla f(y), x - y\rangle\) is the <strong>Bregman distance</strong>.

</div>

<div class="lemma">

<strong>Lemma 3.4.5</strong> (Sufficient Decrease). We have
\[ F(y^+) \leq F(y) - \frac{L}{2}\|y - y^+\|^2. \]

</div>

**Algorithm.** \(x_{n+1} = Tx_n = \operatorname{Prox}_{g/L}\!\left(x_n - \frac{1}{L}\nabla f(x_n)\right)\).

<div class="theorem">
<strong>Theorem 3.4.6</strong> (Rate of Convergence).
<ol>
<li>\((x_n)\) is Féjer monotone w.r.t. \(S\).</li>
<li>\(0 \leq F(x_n) - \mu \leq \frac{L \cdot d_S^2(x_0)}{2n} \in O(1/n)\).</li>
<li>\(x_n \to s \in S\).</li>
</ol></div>

<div class="theorem">

<strong>Theorem 3.4.7</strong> (Convergence of PGM). The iterates \(x_n\) converge to some solution in \(S := \operatorname{argmin}_{\mathbb{R}^m} F(x)\).

</div>

<div class="theorem">

<strong>Proposition 3.4.8.</strong> The following hold:
<ol>
<li>\(\frac{1}{L}\nabla f\) is firmly nonexpansive.</li>
<li>\(\operatorname{Id} - \frac{1}{L}\nabla f\) is firmly nonexpansive.</li>
<li>\(T = \operatorname{Prox}_{g/L}(\operatorname{Id} - \frac{1}{L}\nabla f)\) is \(\frac{2}{3}\)-averaged.</li>
</ol>

</div>

The update operator \(T\) is \(\frac{2}{3}\)-averaged (since \(\operatorname{Prox}_{g/L}\) and \(\operatorname{Id} - \frac{1}{L}\nabla f\) are both \(\frac{1}{2}\)-averaged, and the composition formula applies).

<div class="theorem">

<strong>Theorem 3.4.9.</strong> The PGM iteration satisfies
\[ \|x_{n+1} - x_n\| \leq \frac{\sqrt{2}\, d_S(x_0)}{\sqrt{n}} \in O\!\left(\frac{1}{\sqrt{n}}\right). \]

</div>

<div class="corollary">

<strong>Corollary 3.4.9.1</strong> (Classical Proximal Point Algorithm). Let \(g : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. Fix \(c > 0\). Assume \(S := \operatorname{argmin} g \neq \emptyset\). Update \(x_{n+1} := \operatorname{Prox}_{cg}(x_n)\). Then:
<ol>
<li>\(g(x_n) \downarrow \mu := \min g(\mathbb{R}^m)\).</li>
<li>\(0 \leq g(x_n) - \mu \leq \dfrac{d_S^2(x_0)}{2cn}\).</li>
<li>\(x_n\) converges to a point in \(S\).</li>
<li>\(\|x_{n-1} - x_n\| \leq \dfrac{\sqrt{2}\, d_S(x_0)}{\sqrt{n}}\).</li>
</ol>

</div>

**Special case: Classical Proximal Point Algorithm.** Setting \(f \equiv 0\) (or \(L := 1/c\)):
\[ x_{n+1} = \operatorname{Prox}_{cg}(x_n). \]
Convergence: \(g(x_n) - \min g \leq \frac{d_S^2(x_0)}{2cn}\).

**Special case: ISTA** (Iterative Shrinkage–Thresholding). For \(g(x) = \lambda\|x\|_1\):
\[ \operatorname{Prox}_{g/L}(x) = \left(\operatorname{sign}(x_i)\max\!\left\{0, |x_i| - \frac{\lambda}{L}\right\}\right)_{i=1}^n, \]
the **soft-thresholding** operator. Applied to \(\min \frac{1}{2}\|Ax - b\|^2 + \lambda\|x\|_1\) (LASSO), ISTA gives \(O(1/n)\) convergence.

<div class="example">

<strong>Example 3.6.1</strong> (LASSO). Consider the problem
\[ \min_{x \in \mathbb{R}^m} \frac{1}{2}\|Ax - b\|_2^2 + \lambda\|x\|_1 \]
where \(\lambda > 0\) and \(A \in \mathbb{R}^{n \times m}\). Set \(f(x) = \frac{1}{2}\|Ax-b\|_2^2\) and \(g(x) = \lambda\|x\|_1\). Then \(\nabla f(x) = A^T(Ax - b)\), which is \(L\)-Lipschitz for \(L := \lambda_{\max}(A^T A)\). The problem has a solution since \(f\) is coercive and continuous. Applying PGM (ISTA) gives \(O(1/n)\) convergence; applying FISTA gives \(O(1/n^2)\).

</div>

### 5.4 FISTA: Accelerated Proximal Gradient

The proximal gradient method achieves \(O(1/n)\) convergence, which is optimal for gradient-based methods without additional structure. But Nesterov's remarkable insight is that by adding a carefully chosen "momentum" step — extrapolating beyond the current iterate — one can improve the convergence to \(O(1/n^2)\) without any additional oracle calls. FISTA (Fast Iterative Shrinkage–Thresholding Algorithm) implements this idea.

**Algorithm.** Initialize \(x_0, y_0 = x_0, t_0 = 1\). Update:
\[
t_{n+1} = \frac{1 + \sqrt{1 + 4t_n^2}}{2}, \quad
x_{n+1} = Ty_n, \quad
y_{n+1} = x_{n+1} + \frac{t_n - 1}{t_{n+1}}(x_{n+1} - x_n).
\]

<div class="theorem">

<strong>Proposition 3.5.1.</strong> The sequence \((t_n)_{n \in \mathbb{N}}\) satisfies \(t_n \geq \dfrac{n+2}{2}\).

</div>

<div class="theorem">
<strong>Theorem 3.5.2</strong> (FISTA Convergence). The iterates satisfy:
\[ 0 \leq F(x_n) - \mu \leq \frac{2L \cdot d_S^2(x_0)}{(n+1)^2} \in O\!\left(\frac{1}{n^2}\right). \]</div>

This is a dramatic improvement over PGM's \(O(1/n)\). For LASSO-type problems, FISTA is the method of choice.

### 5.5 Douglas–Rachford Algorithm

When neither \(f\) nor \(g\) is smooth — for instance, in \(\ell^1 + \ell^2\) problems or feasibility problems with two constraint sets — neither gradient descent nor the proximal gradient method applies. The Douglas–Rachford algorithm is designed precisely for this fully non-smooth setting: it uses only the proximal operators of \(f\) and \(g\), not their gradients.

For \(\min f(x) + g(x)\) when neither \(f\) nor \(g\) is smooth (no gradient available), but both proximal operators are computable.

**Setup.** Define the reflections \(R_f = 2\operatorname{Prox}_f - \operatorname{Id}\) and \(R_g = 2\operatorname{Prox}_g - \operatorname{Id}\).

<div class="definition"><strong>Definition</strong> (Douglas–Rachford Operator). \(T_{\mathrm{DR}} = \frac{1}{2}(\operatorname{Id} + R_g R_f).\)</div>

<div class="theorem">
<strong>Lemma 3.7.1.</strong>
<ol>
<li>\(R_f, R_g\) are nonexpansive (since \(\operatorname{Prox}_f\) is f.n.e.).</li>
<li>\(T_{\mathrm{DR}} = \operatorname{Id} - \operatorname{Prox}_f + \operatorname{Prox}_g R_f\).</li>
<li>\(T_{\mathrm{DR}}\) is firmly nonexpansive (\(\frac{1}{2}\)-averaged).</li>
</ol></div>

<div class="theorem">

<strong>Proposition 3.7.2.</strong> \(\operatorname{Fix} T_{\mathrm{DR}} = \operatorname{Fix} R_g R_f\).

</div>

<div class="theorem">

<strong>Proposition 3.7.3.</strong> \(\operatorname{Prox}_f(\operatorname{Fix} T_{\mathrm{DR}}) \subseteq S\).

</div>

<div class="theorem">

<strong>Theorem 3.7.4.</strong> Let \(x_0 \in \mathbb{R}^m\). Update via
\[ x_{n+1} := x_n - \operatorname{Prox}_f(x_n) + \operatorname{Prox}_g(2\operatorname{Prox}_f(x_n) - x_n). \]
Then \(\operatorname{Prox}_f(x_n)\) tends to a minimizer of \(f + g\).

</div>

**Algorithm.**
\[ x_{n+1} = x_n - \operatorname{Prox}_f(x_n) + \operatorname{Prox}_g(2\operatorname{Prox}_f(x_n) - x_n). \]

**Self-Duality.** Remarkably, the Douglas–Rachford operator for the primal problem \(f + g\) equals the DR operator for the Fenchel dual problem \(f^* + (g^*)^v\) (where \(h^v(x) = h(-x)\)). This means a single DR iteration simultaneously tracks both primal and dual iterates.

<div class="lemma">

<strong>Lemma 3.9.1.</strong> Let \(h : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. Define \(h^v(x) := h(-x)\). Then:
<ol>
<li>\(h^v\) is convex, l.s.c., and proper.</li>
<li>\(\partial h^v = -\partial h \circ (-\operatorname{Id})\).</li>
</ol>

</div>

<div class="lemma">

<strong>Lemma 3.9.2.</strong> Let \(h : \mathbb{R}^m \to (-\infty, \infty]\) be convex, l.s.c., and proper. The following hold:
<ol>
<li>\(\operatorname{Prox}_{h^v} = -\operatorname{Prox}_h \circ (-\operatorname{Id})\).</li>
<li>\(R_{h^*} = -R_h\).</li>
<li>\(R_{(h^*)^v} = R_h \circ (-\operatorname{Id})\).</li>
</ol>

</div>

<div class="theorem">

<strong>Theorem 3.9.3.</strong> The primal DR operator \(T_p = \frac{1}{2}(\operatorname{Id} + R_g R_f)\) and the dual DR operator \(T_d = \frac{1}{2}(\operatorname{Id} + R_{(g^*)^v} R_{f^*})\) satisfy \(T_p = T_d\).

</div>

<div class="theorem">

<strong>Theorem 3.9.4.</strong> Let \(x_0 \in \mathbb{R}^m\). Update via \(x_{n+1} := T_p x_n\). Then \(\operatorname{Prox}_f(x_n)\) converges to a minimizer of \(f + g\), and \(x_n - \operatorname{Prox}_f(x_n)\) converges to a minimizer of \(f^* + (g^*)^v\).

</div>

### 5.6 Stochastic Projected Subgradient Method

When \(f = \sum_{i=1}^r f_i\) is a large sum and evaluating the full subgradient is expensive, we may use a stochastic approximation.

**Algorithm.** At each step, sample an index \(i_n\) uniformly from \([r]\) and take a subgradient of only \(f_{i_n}\), scaled by \(r\):
\[ g_n = r f_{i_n}'(x_n), \quad x_{n+1} = P_C(x_n - t_n g_n). \]

**Key properties.** \(E[g_n \mid x_n] \in \partial f(x_n)\) (unbiased) and \(E[\|g_n\|^2 \mid x_n] \leq r \sum_i L_i^2\) (bounded variance). With step sizes satisfying \(\sum t_n = \infty\) and \(\sum t_n^2 / \sum t_n \to 0\) (e.g., \(t_n = \alpha/(n+1)\)):

<div class="theorem"><strong>Theorem 3.8.1.</strong> \(E[\mu_n] \to \mu\) where \(\mu_n = \min_{0 \leq k \leq n} f(x_k)\).</div>

<div class="theorem">

<strong>Proposition 3.8.2.</strong> \(\sup\|\partial f_i(C)\| \leq L_i\) if and only if \(f_i|_C\) is \(L_i\)-Lipschitz. In particular, this holds when \(C\) is bounded.

</div>

### Summary of Convergence Rates

| Algorithm | Setting | Rate |
|---|---|---|
| Projected Subgradient (Polyak) | Non-smooth, constrained | \(O(1/\sqrt{n})\) in \(f\) value |
| Proximal Gradient Method | Smooth \(f\) + non-smooth \(g\) | \(O(1/n)\) in \(F\) value |
| FISTA | Same as PGM | \(O(1/n^2)\) in \(F\) value |
| Douglas–Rachford | Fully non-smooth \(f + g\) | Convergence guaranteed |
| Stochastic PSM | Large-sum, non-smooth | \(E[\mu_n] \to \mu\) |

**The proximal gradient and FISTA hierarchy.** For LASSO-type problems \(\min \frac{1}{2}\|Ax - b\|^2 + \lambda\|x\|_1\): ISTA (PGM) needs \(O(1/\varepsilon)\) iterations for \(\varepsilon\)-accuracy; FISTA needs only \(O(1/\sqrt{\varepsilon})\) — a quadratic speedup.
